# Eisen Krone

Hobby-Spieleprojekt: Mehrere Strategiespiele werden zu einem grossen Spiel kombiniert, das all die Features vereint, die den einzelnen Spielen fehlen.

## Idee

Jedes Strategiespiel hat Stärken, aber auch Lücken. Eisen Krone nimmt die besten Mechaniken aus verschiedenen Spielen und baut daraus ein Spiel, das beides bietet: Tiefe und Vollständigkeit.

## Status

Das Projekt befindet sich am Anfang der Entwicklung.

## Geplante Features

- Features aus verschiedenen Strategiespielen in einem Spiel vereinen
- Fehlende Mechaniken ergänzen, die in den Vorbildern vermisst werden
- Wird laufend erweitert
